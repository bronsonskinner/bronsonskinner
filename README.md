# Engineering Portfolio

The primary purpose of this portfolio is to demonstrate practical engineering capability through projects that integrate hardware, software, experimental validation, and technical documentation. Rather than simply publishing source code, each repository is intended to communicate the complete engineering process, including planning, implementation, testing, analysis, troubleshooting, validation, and lessons learned.

The current featured project is an Automated Raspberry Pi Thermal Characterization Platform developed to investigate the thermal performance of embedded electronic systems. The project integrates Raspberry Pi hardware, Python software, synchronized multi-point temperature acquisition, structured Design of Experiments (DOE), engineering documentation, and repeatable validation methodologies into a reusable experimental platform.

Additional repositories focused on controls engineering, PLC programming, SCADA systems, industrial networking, commissioning, industrial cybersecurity, and advanced manufacturing will be added as they are completed.
